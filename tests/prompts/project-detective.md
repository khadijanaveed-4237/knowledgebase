# Project Detective Test

Ask the Project Detective subagent to analyze the current project.

Check:
1. Project purpose and structure.
2. Important components and their relationships.
3. Actual problems supported by project evidence.
4. Root causes and potential impact.
5. Recommended solutions.

Requirements:
- Inspect the project before making conclusions.
- Distinguish verified facts from assumptions.
- Identify relevant files when possible.
- Do not modify, create, or delete project files.
- Clearly state any limitations.

Return a structured report with findings, evidence, severity, recommendations, and unknowns.
